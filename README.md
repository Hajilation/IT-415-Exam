# Campus Cafeteria POS System

## Description
The Campus Cafeteria POS System is a web-based ordering and payment application developed for Scenario 1 of the IT 415 practical exam. It helps cafeteria cashiers manage customer orders, calculate totals, process cash payments, and generate digital receipts.

## Features
- Displays cafeteria products with their prices.
- Adds products to the cart and adjusts quantities.
- Automatically calculates subtotals and the total amount.
- Validates cash payments and calculates change.
- Generates a receipt after successful payment.
- Prevents duplicate payment processing.
- Allows the cashier to start a new transaction.

## Technologies Used
- **HTML** – System structure
- **CSS** – Interface design and layout
- **JavaScript** – Cart management, payment calculations, and receipt generation

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select products, manage the order, enter the payment amount, and complete the transaction.

## Project Scope
This system uses hard-coded product data and runs in a web browser. It does not require a database or backend server.
